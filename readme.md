# Quest

Quest is an AI-powered employee task and progress management system built with Google Sheets and Google Apps Script.

### Key Features

* Employee task and progress updates
* AI-powered analysis of updates
* Automated weekly reports
* Meeting summaries and action items
* ETA and blocker tracking
* Gamification with XP, levels, and achievements

### Tech Stack

* Google Sheets
* Google Apps Script
* AI API (Gemini/OpenAI)

### Goal

To make employee progress tracking more engaging, automated, and actionable through AI and gamification.
